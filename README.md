# DigiTales

DigiTales is a Digital Storytelling mobile application developed with Flutter.

The application allows parents to create personalized digital stories using images, recorded narration and optional background music. Children can browse and play the available stories through a simplified interface.

## Features

### Parent Mode
- Create, edit and delete stories
- Add images and recorded narration
- Add optional background music
- Search and sort stories
- Import and export stories
- Protected access using device authentication

### Child Mode
- Browse stories in the library
- Play stories with page-flip navigation
- Listen to narration and background music
- AutoPlay

## Technologies
- Flutter
- Dart
- Hive

## Storage
DigiTales works locally on the device. Story data, images and audio files are stored locally.
